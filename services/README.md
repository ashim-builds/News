# SmartSanchar - Express Backend Services (`services`)

This directory contains the Express.js backend microservice for **SmartSanchar (स्मार्ट सञ्चार)**.

For full project documentation, architecture, features, and environment configuration, please refer to the [Root README](../README.md).

## Development Commands

```bash
# Run Development Server with Nodemon
npm run dev

# Start Production Server
npm start
```
