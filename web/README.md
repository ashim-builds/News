# SmartSanchar - Frontend & Web Portal (`web`)

This directory contains the Next.js 16 web application and admin portal for **SmartSanchar (स्मार्ट सञ्चार)**.

For full project documentation, architecture, features, and environment configuration, please refer to the [Root README](../README.md).

## Development Commands

```bash
# Run Development Server
npm run dev

# Build Production Bundle
npm run build

# Start Production Server
npm run start

# Run ESLint
npm run lint
```

App runs locally at: `http://localhost:3000`
